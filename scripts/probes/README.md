# Public API Probes

These scripts are read-only research probes for Flint's public API.

Some probes require the protobuf definitions used by the corresponding
public API environment:

- pi_pb2
- pi_pb2_grpc

Those generated modules are intentionally not represented as private
laboratory files in this repository.

The probes are therefore documented as environment-dependent live
experiments.

Offline result artifacts are included under esults/.

No transaction is submitted by the research workflow.
